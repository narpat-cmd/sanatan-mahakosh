PURPOSE
---------------------------------------------------------------------
Yeh file batati hai ki website mein Sanatan Dharma se jude KYA-KYA
hona chahiye. Isse Claude Code ko content ki poori list milti hai.
Har cheez website ke ANDAR hi padhne/sunne/dekhne layak ho (koi
external link par nirbhar nahi), aur har entry mein source + license
likha ho. Kabhi bhi text khud se na banaya jaye; asli sources se hi
liya jaye, aur jo na mile use "MISSING" mark kiya jaye.

Priority tags:  [P1] pehle  |  [P2] doosre  |  [P3] baad mein
Priority sirf kaam ka order hai; final target = sab kuch.

Naye sections ke liye data\ mein alag file aur (zaroorat par) naya
page banayein, existing structure aur Royal Heritage theme ke saath.
Bade content ko chunked/lazy-loaded rakhein (har adhyay/entry alag).

N. RULES FOR ALL CONTENT
---------------------------------------------------------------------
1. Sab kuch website ke andar; offline + file:// par chale.
2. Asli sources se hi content (Wikisource, GRETIL, sacred-texts,
   Project Gutenberg, open datasets, sarkari/university archives
   jahan license allow kare). Kuch na mile to "MISSING" report.
3. Mool Sanskrit aur purane granth public domain; modern anuvad/
   tika/recordings/photos copyrighted ho sakte hain -> permission ya
   naye original anuvad; har entry mein source + license field.
4. Dharmik sensitivity: tathya sahi, ek sampraday ko doosre se neecha
   dikhane wali language nahi; matbhed hone par "paramparaon ke
   anusaar" likhein; Vedic/Pauranik/lokparampara ka fark batayein.
5. Ayurveda/Jyotish content mein disclaimer: jaankari ke liye, medical
   ya financial salah nahi.
6. Scholar/pandit review board se proofreading (Sanskrit, vidhi,
   tithi) launch se pehle.
7. Verification: har section ke liye count-report (kitne entry, kitna
   missing) data\SCOPE_STATUS.md mein.
8. Bada content chunked/lazy; initial load halka.
9. Devanagari + Hindi + English; Sanskrit mool hamesha sahi Unicode.
10. Pehle Audit & Fix file (SANATAN_Audit_and_Fix_Instructions.txt)
    se maujooda site theek karein, tab naya content jodein.
