# Sanatan — Sampoorna Sanatan Dharma Mahakosh

A royal Indian heritage aesthetic static web application featuring:
- Digital scripture library with interactive 3D flipbook reader
- Divine temples & pilgrimages viewer
- Sanatan minute details encyclopedia
- Search engine

## Deployment
This project is built to be deployed on GitHub Pages.

## Structure
- index.html: Main application layout
- js/: Application logic and modules
- data/: Datasets
- styles/: CSS styles

## Development
To run locally, open `index.html` in any browser.
